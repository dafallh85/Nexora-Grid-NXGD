# Nexora Grid Glossary

## Artificial Intelligence (AI)

Technology that enables software and computer systems to perform tasks that normally require human intelligence.

## Blockchain

A decentralized digital ledger used to record transactions and other information across a distributed network.

## Ethereum

A programmable blockchain network that supports smart contracts and decentralized applications.

## Web3

An ecosystem built around blockchain networks, decentralized applications, digital assets, and decentralized technologies.

## Data Intelligence

The process of collecting, processing, analyzing, and interpreting data to generate useful information.

## Smart Contract

A program deployed on a blockchain that executes predefined functions according to its programmed logic.

## ERC-20

A widely used Ethereum token standard for fungible digital tokens.

## NXGD

The token symbol associated with the Nexora Grid project.

## Nexora Grid

A project exploring the convergence of AI, data intelligence, blockchain, automation, and Web3.

## AI Infrastructure

Technology infrastructure designed to support artificial intelligence services, processing, and applications.

## Data Infrastructure

Systems used to collect, process, organize, store, and provide access to data.

## Automation

The use of software and technology to perform tasks or workflows with limited manual interaction.

## Decentralized Application (DApp)

An application that uses blockchain-based infrastructure or smart contracts as part of its operation.

## API

An Application Programming Interface that allows software systems to communicate and exchange structured data or functionality.

## SDK

A Software Development Kit containing tools and resources that help developers build applications for a specific platform or ecosystem.

## Staking

A mechanism that may allow users to commit digital assets to a blockchain or application in return for defined benefits or rewards, depending on the implementation.

## Governance

A system that may allow participants to contribute to decisions affecting a decentralized ecosystem.

## Tokenomics

The economic structure of a digital asset, including supply, allocation, utility, and distribution.

## Liquidity

Assets made available to facilitate trading or other transactions within a market or protocol.
